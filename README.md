🤖 GarAI: Autonomous HFT & Quant Trading Ecosystem
Este repositorio contiene el "Cerebro" y la infraestructura operativa de una firma de High Frequency Trading (HFT) y análisis cuantitativo, operada y orquestada enteramente por un equipo de agentes de Inteligencia Artificial.

La visión del proyecto es construir una empresa escalable, rentable y automatizada, con una base científica y matemática rigurosa, donde la intervención humana del Operador Principal se reserva exclusivamente para la toma de decisiones estratégicas.

🏢 Estructura Organizacional (Red de Agentes)
El sistema funciona bajo un esquema corporativo descentralizado. Cada nodo opera con un rol específico, alimentado por archivos de contexto de identidad (USER.md, SOUL.md, VISION.md):

GarAI 🤖 (CEO & Nodo Central): Orquestador general. Toma decisiones de alto nivel, evalúa la rentabilidad, supervisa la infraestructura general y delega tareas para asegurar la alineación con la visión a largo plazo.

Sudo (Arquitecto de Sistemas): Encargado de la infraestructura, optimización de baja latencia, despliegue de código seguro y escalabilidad técnica del entorno.

Lana (Directora Financiera): Responsable del control de riesgos, gestión de capital, análisis de gastos y la progresiva automatización administrativa.

ROI-berto (Investigador Cuantitativo): Análisis de datos, modelado estadístico, investigación profunda de mercados y detección de oportunidades con alta rentabilidad.

⚙️ Stack Tecnológico e Infraestructura
La arquitectura está diseñada para el crecimiento metódico, la optimización extrema de recursos y una ejecución ininterrumpida (24/7):

Motor LLM: Gemini 3.1 Flash Lite (optimizado para velocidad de inferencia y costo-eficiencia en operaciones continuas).

Entorno de Ejecución: Servidores Virtuales Privados (Ubuntu Linux) de alta disponibilidad.

Orquestación de Procesos: PM2.

Desarrollo y Scripts: Python, Node.js, Google Apps Script.

Gestión de Versiones: Git/GitHub (Auto-comiteado de forma autónoma por GarAI).

📊 Operaciones y Entornos Actuales
Mercados Descentralizados: Operación algorítmica y Sniper Bots en plataformas predictivas (Polymarket CLOB V2).

Renta Variable y Fija: Tracking automatizado e integración de datos de mercado tradicionales (InvertirOnline, Interactive Brokers).

🚀 Roadmap y Evolución
Consolidación HFT: Refinar modelos matemáticos y optimizar la latencia en las ejecuciones de mercado para maximizar ganancias.

Expansión Cuantitativa: Integrar nuevos mercados, APIs y fuentes de datos para potenciar las estrategias de ROI-berto.

Automatización Administrativa Zero-Touch: Delegar gradualmente en Lana las tareas operativas (declaraciones de impuestos, control de pagos recurrentes, reservas logísticas corporativas) para lograr una verdadera autonomía empresarial.
